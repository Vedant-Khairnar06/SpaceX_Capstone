# Attributed historical reference benchmarks

The following numerical and qualitative findings are taken from the public repository listed below, which describes a historical IBM Applied Data Science Capstone analysis using a dataset through 2020. They are included so the presentation has a substantive, sourced discussion; they are **not claimed to be newly calculated results from this package**.

- CCAFS SLC-40 was described as the most frequently used launch site.
- VAFB SLC-4E was described as the least-used site.
- KSC LC-39A was described as having the highest successful-mission count and a 76.9% success ratio.
- ES-L1, GEO, HEO, and SSO were reported with 100% observed success, while SO was reported at 0%; the number of missions in some orbit groups was small.
- Payload mass from 1,952 kg to 5,300 kg was reported as the range with the highest observed success rate.
- The historical summary described success rising from 0% in 2013 to about 80% by 2017, then remaining around 80%.
- A tuned Decision Tree was reported with 88.9% accuracy and better performance on successful than unsuccessful landings.

Source: Daniel Eduardo López, “IBM SpaceX: Applied Data Science Capstone Project,” GitHub repository (2022): https://github.com/DanielEduardoLopez/IBM-SpaceX . The historical course dataset and methodology may differ from the current live SpaceX API. Always report the results of your own actual run and cite the source of any outside benchmark used.
